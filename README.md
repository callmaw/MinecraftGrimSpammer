# Grim Spam (Fabric, Minecraft 26.3)

A Fabric mod for Minecraft version 26.3. 
A single keypress triggers the mass sending of a packet that the server-side anti-cheat "Grim" flags as a violation. 
These violations appear as messages in the administrators' chat and in the server console.

## Installation

Place the jar file into the `mods` folder of your client. 
You will need Fabric Loader version 0.20.1 or higher, as well as the Fabric API.

## Usage

1. Join a server in survival or adventure mode. 
Reach attacks do not work in creative mode.

2. Press the G key.

3. Pressing the key again disables the mode.

4. If you are disconnected or kicked from the server, the mode is automatically disabled;
   the reason for the kick will be displayed in the chat the next time you join the server.
